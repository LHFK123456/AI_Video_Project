# 音频转视频工具 · 使用说明

## 一、最快用法（不用敲命令）

**方式 A：拖拽**
直接把音频文件（或一批音频）拖到 `按这里开始.bat` 图标上，松手就跑。

**方式 B：放文件夹**
1. 把音频放进 `input` 文件夹
2. 双击 `按这里开始.bat`
3. 跑完会自动弹出 `output` 文件夹

支持 mp3 / wav / m4a / flac / aac / ogg / opus / wma。
中文名、空格、括号都没问题（已实测）。

默认会自动生成深蓝渐变背景 + 底部音频波形，画面跟着音乐动，首尾 0.5 秒淡入淡出。
显卡加速默认开启，5 分钟音频约 30 秒出片。

## 二、想要更好看，加参数

在 `audio2video` 目录下打开命令行，用 `python a2v.py 音频 --参数` 的形式。

**加封面图（推荐，比纯渐变好看）**
```
python a2v.py 我的歌.mp3 -i 封面.jpg --title "歌名 · 歌手"
```

**竖屏（抖音/视频号）**
```
python a2v.py 我的歌.mp3 -i 封面.jpg --size vertical --title "歌名"
```

**多图卡点（图片跟着节奏切换）**
```
python a2v.py 我的歌.mp3 --images 图片文件夹 --per 2.0 --title "歌名"
```
`--per 2.0` 是每张图停 2 秒，不写就按音乐时长平均分。

**烧入字幕**
把 `我的歌.srt` 放成同名文件，它会自动找到；也可以手动指定：
```
python a2v.py 我的歌.mp3 --subtitle 歌词.srt
```

**封面是方图或竖图，不想被裁掉**
```
python a2v.py 歌.mp3 -i 方图.jpg --fit blur      # 模糊铺底 + 原图居中（最好看）
python a2v.py 歌.mp3 -i 方图.jpg --fit contain   # 纯色边 + 原图居中
```

## 三、参数速查

| 参数 | 作用 |
|---|---|
| `-i 图片` | 封面图 |
| `--images 路径或目录` | 多图卡点 |
| `--per 秒数` | 卡点每张图时长 |
| `--size vertical` | 竖屏 1080x1920，另有 `square` `4k` `720p` `1920x1080` |
| `--title "文字"` | 叠加标题 |
| `--subtitle x.srt` | 烧字幕 |
| `--fit cover/blur/contain` | 封面适配方式 |
| `--wave` / `--no-wave` | 强制开/关波形 |
| `--wave-color 0x6E9BFF` | 波形颜色 |
| `--wave-height 200` | 波形高度 |
| `--bg 0x101014` | 纯色背景（不用渐变） |
| `--crf 18` | 画质，越小越清晰（默认20） |
| `--hwenc off` | 强制用 CPU 的 x264 编码 |
| `--loudnorm` | 响度标准化到 -16 LUFS（适合发平台） |
| `--fade 0` | 关掉首尾淡入淡出 |
| `--tag _v2` | 输出文件名加后缀 |
| `--dry-run` | 只看命令不执行 |
| `--doctor` | 环境自检 |

## 五、常见问题

**Q：能不能处理整张专辑？**
A：把所有 mp3 丢进 `input`，直接运行，会批量转完。

**Q：视频太大？**
A：加 `--crf 24`，或者 `--preset slow` 换更小的体积。

**Q：想要更酷的动态背景？**
A：现在背景是程序生成的渐变+柔光。如果你有视频素材，我可以再加一个「用视频当背景」的模式。
